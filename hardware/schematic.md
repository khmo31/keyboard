# 하드웨어 핀 연결 상세도 — PIO-USB 방식

## 부품별 핀 배열

### USB A 타입 암커넥터 (브레이크아웃)

USB A 암커넥터는 보통 4핀 브레이크아웃 보드 형태로 판매된다. 위에서 봤을 때:

```
    ┌──────────────────┐
    │  ██████████████  │  ← USB A 포트 (키보드 USB 케이블 꽂는 곳)
    │                  │
    │  V  D- D+ G      │  ← 핀 실크스크린
    │  B     N         │
    │  U     D         │
    │  S               │
    └──────────────────┘
```

| 핀 | 레이블 | 와이어 색상 (USB 표준) | 연결 대상 |
|----|--------|----------------------|-----------|
| VBUS | V / 5V / VBUS | 적색 | Pico VBUS (물리핀 40) |
| D- | D- / DM | 백색 | 22Ω 저항 → Pico GP1 (물리핀 2) |
| D+ | D+ / DP | 녹색 | 22Ω 저항 → Pico GP0 (물리핀 1) |
| GND | G / GND | 흑색 | Pico GND (물리핀 3) |

## 22Ω 저항 상세

D+/D- 라인에 22Ω 직렬 저항을 삽입하는 이유:
- USB 2.0 규격은 D+/D- 라인에 22~45Ω 직렬 저항을 요구 (임피던스 매칭)
- RP2040 GPIO 출력 임피던스 + 22Ω ≈ USB 요구 임피던스
- 없어도 동작할 수 있으나 신호 반사로 인한 간헐적 통신 오류 가능

**연결 방법 (브레드보드):**
```
GP0 (Pico 1번) ── 점퍼와이어 ──[22Ω 저항]── 점퍼와이어 ── USB D+
GP1 (Pico 2번) ── 점퍼와이어 ──[22Ω 저항]── 점퍼와이어 ── USB D-
```

## 추가 참고사항

### USB 3.0 / 고속 장치 미지원
PIO-USB Host는 Full-Speed(12Mbps)와 Low-Speed(1.5Mbps)만 지원한다. USB 3.0 전용 키보드는 High-Speed(480Mbps)라서 직접 연결 시 인식되지 않는다. **해결책: USB 2.0 허브를 중간에 연결하면 허브가 HS→FS로 변환해준다.**

### USB 허브 지원
Pico-PIO-USB는 USB 허브를 지원한다. 키보드 + 마우스 동시 연결 등 다중 장치 구성이 필요하면 USB 2.0 허브를 USB A 커넥터에 연결하면 된다.

### GPIO 전압 안전성
- Pico의 모든 GPIO는 **3.3V only** (5V tolerant 아님)
- USB LS/FS는 3.3V 차동 신호를 사용하므로 GPIO 직결이 안전
- VBUS(5V)는 절대 GPIO에 직접 연결하지 말 것 (Pico 파손)
- VBUS는 반드시 Pico의 VBUS 핀(40번) 또는 VSYS 핀(39번)에만 연결
