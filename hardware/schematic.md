# 하드웨어 핀 연결 상세도 — USB Host Shield V560

## V560 실물 기준 ICSP 핀맵

**⚠️ V560은 MAX3421E 칩을 사용한 Arduino Shield 폼팩터 클론이다. SPI는 ICSP 2×3 헤더로 연결한다.**

### ICSP 2×3 헤더 표준 핀맵

```
         V560 보드 가장자리 ICSP 헤더
         (핀 1 위치에 작은 △ 삼각형 마크)

         ┌──────────────┐
   MISO  │1 ●  삼각형   2│  VCC (5V)
    SCK  │3 ●          4│  MOSI
  RESET  │5 ●          6│  GND
         └──────────────┘
```

## ICSP 헤더 ↔ Pico 연결 (7개 와이어)

**SPI 6핀 + 추가 SS 1핀 = 총 7개 연결:**

| ICSP 핀 | 신호 | → | Pico GPIO | Pico 물리핀 | 설명 |
|---------|------|---|-----------|------------|------|
| ICSP-1 | MISO | → | **GP16** (SPI0 RX) | 21 | Shield → Pico 데이터 수신 |
| ICSP-2 | VCC (5V) | → | **VBUS** | 40 | 5V 전원 |
| ICSP-3 | SCK | → | **GP18** (SPI0 SCK) | 24 | SPI 클럭 |
| ICSP-4 | MOSI | → | **GP19** (SPI0 TX) | 25 | Pico → Shield 데이터 송신 |
| ICSP-5 | RESET | → | **GP15** | 20 | MAX3421E 리셋 (Active Low) |

| V560 디지털 핀 | 신호 | → | Pico GPIO | Pico 물리핀 | 설명 |
|----------------|------|---|-----------|------------|------|
| D10 | SS (CS) | → | **GP17** (SPI0 CSn) | 22 | SPI 칩 셀렉트 (Active Low) |

```
와이어 색상 배정 (제안):
  ICSP-1 MISO   ────주황────  Pico GP16 (물리핀 21)
  ICSP-2 VCC    ────빨강────  Pico VBUS (물리핀 40)
  ICSP-3 SCK    ────갈색────  Pico GP18 (물리핀 24)
  ICSP-4 MOSI   ────노랑────  Pico GP19 (물리핀 25)
  ICSP-5 RESET  ────파랑────  Pico GP15 (물리핀 20)
  ICSP-6 GND    ────검정────  Pico GND  (물리핀 38)
  D10 SS        ────초록────  Pico GP17 (물리핀 22)
```

### 택트 스위치

| 스위치 핀 | → | Pico GPIO | Pico 물리핀 |
|-----------|------|-----------|------------|
| 다리 1 | → | GP20 | 26 |
| 다리 2 | → | GND | 28 |

## ⚠️ 솔더 점퍼 브릿지 (필수)

V560 클론 보드는 출하 시 아래 3개의 솔더 점퍼가 **열려 있다**. 납땜하지 않으면 전원이 안 들어와서 완전 무반응이다.

| 점퍼 위치 | 동작 | 주의 |
|-----------|------|------|
| **3.3V 패드** (좌측, 2개 패드) | 두 패드를 솔더로 브릿지 | MAX3421E 로직 전원 |
| **5V 패드** (좌측, 2개 패드) | 두 패드를 솔더로 브릿지 | 레벨 시프터 전원 |
| **VBUS PWR → 5V** (USB 포트 근처, 3개 패드 중 선택) | 가운데 + 5V 표시된 패드를 브릿지 | **절대 3.3V 선택 금지** — USB 장치가 동작 안 함 |

점퍼 위치는 보드 실크스크린의 `3.3V`, `5V`, `VBUS PWR` 표시를 확인할 것.

## 추가 핀 (선택적 연결)

V560 Shield에는 다음 추가 핀들이 있다. 지금은 연결하지 않아도 되지만, 추후 활용 가능:

| Shield 핀 | 위치 | 신호 | 용도 |
|-----------|------|------|------|
| **D9** | 디지털 헤더 | INT (인터럽트) | USB 장치 연결 감지. Pico의 GP14에 연결하면 폴링 대신 인터럽트 방식 가능 |
| **D7** | 디지털 헤더 | GPX | 범용 출력/입력. 보통 미사용 |
| **D8** | 디지털 헤더 | RESET (중복) | ICSP-5와 동일한 RESET 신호. 둘 중 하나만 연결하면 됨 |

## SPI 통신 설정

- **모드:** SPI Mode 0 (CPOL=0, CPHA=0)
- **클럭 속도:** 1MHz (안정적) ~ 26MHz (최대)
- **MAX3421E는 슬레이브 전용 칩.** Pico가 SPI 마스터
- **SS (GP17)**: Active Low. SPI 통신 시작 전 LOW, 종료 후 HIGH

## 전압 및 GPIO 안전성

| 항목 | 값 | 확인 |
|------|-----|------|
| V560 I/O 전압 | 3.3V | MAX3421E의 VL 핀이 내장 3.3V 레귤레이터로 공급 → SPI는 3.3V |
| Pico GPIO 허용 전압 | 3.3V (5V tolerant 아님) | ✅ V560 SPI가 3.3V이므로 직결 안전 |
| 전체 소비 전류 | ~180mA 이하 | USB 포트 500mA 제한 내. Shield 50mA + Pico 30mA + 키보드 100mA |

**Pico GPIO(3.3V only) ↔ V560 SPI(3.3V) 직결 안전. 레벨 시프터 불필요.**

## 전원 주의

1. **Shield에는 Pico의 VBUS(5V)로 전원 공급.** Shield 자체에 3.3V 레귤레이터 내장
2. **Pico는 USB 케이블로 PC에서 전원 공급** — 별도 전원 불필요
3. **USB 포트의 5V(GPIO VBUS)를 ICSP-2에 직결.** Shield 내부에서 3.3V로 레귤레이션됨

## V560 vs MAX3421E Mini (기존 설계) 차이점

| 항목 | MAX3421E Mini (기존) | USB Host Shield V560 (현재) |
|------|---------------------|---------------------------|
| 크기 | ~30×20mm | ~53×53mm (Arduino Shield) |
| SPI 연결 | 6핀 단일 열 | ICSP 2×3 헤더 |
| SS 핀 | 6핀 열에 포함 | 별도 D10 핀에서 가져와야 함 |
| 추가 핀 | 없음 | INT(D9), GPX(D7), RESET(D8) |
| 솔더 점퍼 | 없음 (바로 사용 가능) | **3개 브릿지 필수** |
| 3.3V 레귤레이터 | 내장 | 내장 (AMS1117-3.3 등) |
| 점퍼 와이어 | 6개 | **7개** (SS 추가) |
